# AI Quota 设计说明

## 目标

把 CodexBar 定制为 macOS 14+ 菜单栏应用 **AI Quota**，首版仅监控当前本机登录的 Codex 与 Claude 账号。应用默认每分钟刷新，状态栏每 8 秒轮换一个 Provider，并始终显示“已使用”百分比。

## 产品决策

- Adopt / Extend：复用 CodexBar 的 Codex OAuth + app-server、Claude OAuth + CLI、缓存、刷新、通知和登录启动能力；只扩展产品配置与展示层。
- 状态栏采用方案 C：Provider 彩色标记，右侧上下两行分别显示 `5H` 和 `WEEK` 的已使用百分比；过旧数据降低透明度并附加 `!`。
- 点击状态栏采用方案 A：总览中按 Provider 分组显示 5 小时和周额度进度、重置时间、刷新状态；底部保留“设置”和“刷新”。
- 首次运行默认启用简体中文、1 分钟刷新、8 秒轮换、80%/95% 已使用阈值通知、额度恢复通知和登录时启动。
- Provider 失败互不阻塞。保留最近一次成功值；有历史值时连续 3 次刷新失败才显示为过旧。
- 不新增分析埋点、屏幕录制、辅助功能权限或全盘扫描。
- 分发为 arm64 + x86_64 的未签名 ZIP，Bundle ID 为 `com.matype.aiquota`。

## 数据与状态

`UsageStore` 继续作为唯一数据源。AI Quota 展示模型只读取 `UsageSnapshot` 中的语义窗口：1–12 小时窗口作为 5H，7 天窗口作为 WEEK。百分比在展示层钳制到 0...100；缺失窗口显示 `--`。

刷新失败不会清空快照。连续失败门槛从“第 2 次显示错误”调整为“第 3 次显示错误”。成功刷新会清零失败计数。重置与阈值去重继续由上游窗口状态机负责。

## 设置

AI Quota 设置页只暴露首版需要的项目：

- Codex / Claude 启用开关与登录入口
- 刷新间隔
- Provider 轮换间隔
- 80% / 95%（可调整）通知阈值
- 通知开关
- 登录时启动

底层高级配置继续保留以兼容采集器，但不出现在 AI Quota 的主设置界面。

## 验收

- 新增展示、轮换、默认值、连续失败门槛测试全部通过。
- 状态栏能轮换 Codex / Claude，并显示两类已使用百分比。
- 总览同时展示所有已启用 Provider 的卡片，支持刷新和打开设置。
- `AI Quota.app` 可构建并打包为未签名 ZIP。
- 不新增上游基线之外的测试失败。
